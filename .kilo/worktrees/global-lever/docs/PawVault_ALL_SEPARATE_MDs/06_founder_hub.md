# PawVault --- Founder Hub

Founder Hub main idea

\- Founder Hub is the main control centre - Founder should be able to
manage almost everything from here - Dashboard - Quick actions - Website
status - Server status - Database status - CDN status - Current users -
Total users - Total creators - Total products - Orders - Revenue -
Reports - Errors - Performance - Recent activity - Recent moderation -
Recent sales - System alerts - Important warnings - Quick maintenance
mode - Quick publish - Quick rollback
