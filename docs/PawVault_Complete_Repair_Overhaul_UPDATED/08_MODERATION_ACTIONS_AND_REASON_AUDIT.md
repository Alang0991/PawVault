# PawVault --- Moderation Actions, Reasons & Audit

## Actions

Support the actual permitted workflow: Review, Request Changes, Suspend,
Remove, Restore, Dismiss Report, Escalate.

Only show actions granted to the current role.

## Reasons

Suspension/removal must require a reason. Store creator-facing
explanation separately from private internal notes when needed.

## Audit log

Record actor, role, target, action, reason, previous state, new state,
timestamp and evidence/reference.

## Restore/appeals

Restores and appeal decisions must create new audit entries, never
overwrite history.

## Security

Moderator is not Administrator. Founder authority is highest but remains
auditable. No destructive mystery actions.
