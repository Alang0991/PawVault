# PawVault --- Vision & Website

**Bluey:**

PawVault --- FULL NOTES / IDEAS

Main idea

\- PawVault needs to be a proper platform / marketplace - Want it to
have the same general type of functionality as the current PawVault
setup but keep improving it - Founder Hub should basically be the
control centre for the entire website - Want to be able to change things
on the website without constantly editing the actual website code - Need
Founder controls - Need Creator controls - Need normal User controls -
Need proper permissions between all 3 - Staff should have their own
permissions too - Need to keep everything optimized from the start -
Don't add random features that make the website slow - If something
isn't being used it shouldn't be loading for everyone - Make things
modular - Make things easy to expand later - Make the whole thing work
properly on mobile as well as desktop - Want it to look professional but
not overly complicated - Normal users shouldn't see all the complicated
admin stuff - Creators should only see things they actually need -
Founder should have full control

Website

\- Homepage - Marketplace - Search - Product pages - Creator pages -
Creator stores - Wishlist - Cart - Checkout - Orders - Downloads -
Licences - Reviews - Notifications - User profiles - Account settings -
Creator dashboard - Tutorials - Help/support - API/developer section -
About - Contact - Terms - Privacy - Cookie settings - Other legal pages
as needed

Homepage

\- Main homepage - Main hero/banner - Website introduction - Featured
products - Featured creators - New products - Popular products -
Trending products - Free products - Sales/promotions - Announcements -
Creator spotlights - Product spotlights - Custom homepage sections -
Founder can enable/disable sections - Founder can reorder sections -
Founder can change homepage text - Founder can change homepage images -
Founder can change banners - Founder can schedule homepage changes -
Homepage preview before publishing - Different seasonal homepage
layouts - Homepage can automatically change depending on month/event -
Don't need to manually edit the website every time something changes

Website navigation

\- Main navigation - Marketplace - Products - Creators - Tutorials -
Search - Wishlist - Cart - Notifications - Account - Creator dashboard
if creator - Founder Hub if founder - Support - Footer navigation -
Founder should be able to change navigation - Ability to add/remove
navigation items - Ability to reorder navigation items - Don't let
creators/users change global navigation
