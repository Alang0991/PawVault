# PawVault --- Permissions, Security & Moderation

Moderation

\- User reports - Product reports - Creator reports - Review reports -
Copyright reports - Moderation queue - Product approval - Creator
approval - Content removal - Warnings - Suspensions - Bans - Appeals -
Moderation logs - Staff notes - Report history - Need permissions so
normal staff can't access things they shouldn't

Security

\- Account security - MFA/2FA - Login monitoring - Session management -
Device management - Suspicious login detection - Email verification -
Creator verification - Staff permissions - Founder permissions - Audit
logs - Security logs - Backups - Restore points - Security settings -
Sensitive changes need confirmation - Important security actions need to
be logged

Permissions system

Founder

\- Full access - Full website control - Full marketplace control - Full
creator control - Full user control - Full moderation control - Full
payment control - Full currency control - Full language control - Full
analytics - Full security control - Full system control - Manage staff -
Create staff roles - Change staff permissions - Remove staff access -
Override creator/user permissions - Access database controls - Access
server/system controls - Access backups - Access staging - Publish
changes - Rollback changes - Emergency maintenance mode - Global website
shutdown if ever needed

Creator

\- Own profile - Own storefront - Own products - Own collections - Own
sales - Own orders - Own revenue - Own downloads/analytics - Own
reviews - Own payouts - Own product updates - Own storefront
customization - Own announcements where allowed - Own discount/sale
settings where allowed - Cannot edit main website - Cannot access
Founder Hub - Cannot edit other creators - Cannot manage users - Cannot
ban users - Cannot manage marketplace - Cannot manage global categories

**Bluey:**

\- Cannot manage global tags - Cannot manage currencies globally -
Cannot manage languages globally - Cannot manage payments globally -
Cannot access platform-wide analytics - Cannot access database - Cannot
access server settings - Cannot change security settings - Cannot manage
other creators

User

\- Own account - Own profile - Browse marketplace - Search - Filter -
View products - View creators - Purchase - Wishlist - Follow creators -
Download purchases - View orders - View licences - Leave reviews -
Manage notifications - Manage language - Manage currency - Manage
appearance - Manage security - Cannot upload products - Cannot manage
products - Cannot manage creators - Cannot manage users - Cannot access
Founder Hub - Cannot access creator dashboard - Cannot access
moderation - Cannot manage payments - Cannot change global settings

Staff roles

\- Founder - Admin - Moderator - Support - Finance - Developer - Content
Manager - Marketplace Manager - Could create custom staff roles - Don't
give everyone full admin access - Individual permissions - Website
access - Marketplace access - Creator management - User management -
Moderation - Payments - Analytics - Support - Content management -
Security - API - System controls - Founder can change permissions -
Founder can revoke access - Founder can see staff actions - Staff
actions need audit logs
