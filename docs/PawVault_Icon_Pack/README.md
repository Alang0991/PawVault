# PawVault — Tabler Icon Pack

This folder contains a curated subset of the free, MIT-licensed Tabler Icons
for use in the PawVault website.

## Recommended usage
- Use the outline SVGs as the default UI icons.
- Use filled icons sparingly for active/selected states.
- Keep one consistent icon family throughout PawVault.
- Prefer CSS-controlled sizing/color rather than editing individual SVG files.
- The icon filenames are the official Tabler icon names.

## Groups
The folders are organized by PawVault feature area so Kilo can find icons quickly.

## Source
Official project: https://github.com/tabler/tabler-icons
Official icon site: https://tabler.io/icons

## Important
This is a curated PawVault subset, not the entire Tabler repository.
The original Tabler license and notices remain applicable to the icon artwork.
